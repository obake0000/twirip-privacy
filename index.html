拡張機能名: Twitter AI Bulk Reply

本拡張機能（以下「本拡張機能」）は、ユーザーのプライバシーを最大限尊重します。本ポリシーは、本拡張機能が取り扱うデータの種類、利用目的、保存場所について説明します。

1. 収集するデータ

本拡張機能は、以下のデータをユーザーのブラウザのローカルストレージにのみ保存します。外部サーバーや開発者への送信は一切行いません。

データ用途保存場所
Claude APIキーAIリプライ生成のためのAPI呼び出しchrome.storage.sync
シークレットコード本拡張機能の利用認証chrome.storage.local
カスタムプロンプトユーザーが設定したプロンプトの保存chrome.storage.sync
投稿履歴重複投稿の防止（30日間）chrome.storage.local
取得したツイートUI表示・処理用の一時データchrome.storage.local
広告除外キーワード広告ツイートの自動除外chrome.storage.local
検索キーワードユーザーが保存したキーワードchrome.storage.local

2. 第三者への送信

本拡張機能は、ユーザーが取得したツイート内容を以下の用途でのみ第三者APIへ送信します。

  • Anthropic（Claude API）: ユーザーが「リプライ生成」ボタンを押した時のみ、ツイート本文をリプライ生成のためにAnthropic社のAPIへ送信します。送信先のプライバシーポリシーは https://www.anthropic.com/privacy を参照してください。
  • X（旧Twitter）: 本拡張機能は X.com / twitter.com 上で動作し、当該サイトの公開ツイートを取得・リプライ投稿のためにDOM操作を行います。

上記以外への送信は一切行いません。開発者や第三者がユーザーデータを収集・閲覧することはありません。

3. データの取り扱いに関する宣言

  • 本拡張機能は、ユーザーの個人を特定する情報（氏名、住所、電話番号等）を一切収集しません。
  • 収集したデータの販売・第三者提供は一切行いません。
  • 広告・トラッキング・分析目的のデータ収集は行いません。
  • すべてのユーザーデータは、ユーザー自身のブラウザ内にのみ保存されます。

4. データの削除

ユーザーは以下の方法でいつでもデータを削除できます。

  • 拡張機能の設定画面から「履歴をクリア」ボタンで履歴データを削除
  • Chromeの拡張機能管理画面から本拡張機能をアンインストールすると、すべてのローカルデータが削除されます

6. ポリシーの変更

本ポリシーは予告なく変更される場合があります。重要な変更がある場合は、本拡張機能のアップデート時に通知します。

7. お問い合わせ

本ポリシーや本拡張機能に関するお問い合わせは、Chrome Web Storeのサポートタブよりご連絡ください。
